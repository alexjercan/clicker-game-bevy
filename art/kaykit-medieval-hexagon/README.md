# KayKit Medieval Hexagon source assets

This directory contains the unused glTF exports from KayKit Medieval Hexagon
Pack 1.0 FREE by Kay Lousberg. The five models used by the game and their
required buffers and textures remain under `assets/gltf/`.

The source archive was downloaded from
[itch.io](https://kaylousberg.itch.io/kaykit-medieval-hexagon) on 2026-09-19:

- File: `KayKit_Medieval_Hexagon_Pack_1.0_FREE.zip`
- SHA-256: `4fbb374c45732c88522bd3439e9415bf568c683236ede336b4e61d161155ba12`
- Distributed pack creation date: 2024-04-26

The combined `art/kaykit-medieval-hexagon/gltf/` and `assets/gltf/` trees are
byte-identical to the archive's `Assets/gltf/` tree. No model, buffer, or
texture was transformed. The archive also contains FBX, Unity FBX, and OBJ
exports. Those duplicate formats are not stored in this repository.

[`credits/licenses/KayKit_Medieval_Hexagon_CC0-1.0.txt`](../../credits/licenses/KayKit_Medieval_Hexagon_CC0-1.0.txt).
